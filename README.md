# 🚀 Project Aetheris — Europa Space Exploration Portal

An educational, interactive website designed for the **Technology Student Association (TSA) Website Design** competition. Project Aetheris introduces students and the general public to a fictional deep-space mission exploring the liquid ocean beneath the icy crust of Jupiter's moon, **Europa**.

## ✨ Key Features
* **Mission Control (`index.html`):** Explains the mission goals and future significance of exploring Europa, paired with a real-time spaceship telemetry tracker and an interactive **Student Boarding Pass** generator.
* **Crew Directory (`crew.html`):** Showcases 8 diverse space careers across 4 categories (Flight, Engineering, Science, and Medical/Comms) with live department filter buttons and custom SVG astronaut portraits.
* **Spacecraft Technology (`technology.html`):** Features an interactive spaceship blueprint with clickable hotspots that open diagnostic pop-ups, plus a functional **Rocket Weight & Fuel Calculator**.
* **Night-Vision Cabin Mode:** An accessibility toggle button in the top navigation bar that switches the interface to low-glare red tones and saves the user's preference across pages using `localStorage`.

## 🛠️ Technologies Used
* **HTML5:** Semantic structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) and accessible form inputs.
* **CSS3:** Custom CSS variables, Flexbox, responsive CSS Grid layouts, media queries, and frosted-glass UI styling.
* **Vanilla JavaScript:** DOM manipulation, event listeners, form validation, `setInterval()` telemetry updates, and `localStorage` state management.
